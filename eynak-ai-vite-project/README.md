# مدیر رشد اینستاگرام (AvalAI Edition)

## اجرا
```
npm install
npm run dev
```
بعد آدرس `http://localhost:5173` رو باز کن.

## اتصال AvalAI
کلید و اسم مدل رو توی نوار بالای اپ وارد کن. اگه خالی بمونه، Claude داخلی استفاده میشه.

## اگه باز هم خطا داد (CORS)
یعنی AvalAI اجازه‌ی درخواست مستقیم از مرورگر رو نمی‌ده. راه‌حل: یه پروکسی ساده Node/Express بساز که کلید رو سمت سرور نگه داره و درخواست رو ازونجا بفرسته؛ آدرس fetch توی `src/App.jsx` (تابع `askClaude`) رو به آدرس همون پروکسی تغییر بده.
